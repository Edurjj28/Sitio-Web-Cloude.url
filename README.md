# CloudStock

Página web estática sobre Computación en la Nube.

## Tecnologías
- HTML5
- CSS3
- JavaScript básico

## Contenido
- Qué significa computar
- Qué es Cloud Computing
- SaaS, PaaS e IaaS
- Computación local vs Cloud
- Ruta desde HTML local a un sitio público
- Hosting, HTTP/HTTPS, IP, DNS y Deploy
- Proyecto transversal CloudStock
