CONCEPTO PRINCIPAL

¿Qué es Cloud Computing?

Computar

Computar es procesar información mediante recursos tecnológicos. Un computador recibe datos, los procesa, puede almacenarlos y entrega un resultado.

CPU RAM Almacenamiento SO Aplicaciones Red

☁ Cloud Computing

Es el uso bajo demanda de recursos informáticos a través de una red, normalmente Internet.

Puede incluir almacenamiento, servidores, bases de datos, aplicaciones, procesamiento y redes.

Idea clave: La nube utiliza infraestructura física real. Existen servidores físicos en centros de datos, pero el usuario no necesita poseer ni administrar toda esa infraestructura.
03

MODELOS DE SERVICIO

SaaS, PaaS e IaaS

S

SaaS

Software como servicio

Usamos una aplicación lista para funcionar.

Ejemplo: Microsoft 365.

P

PaaS

Plataforma como servicio

Desplegamos aplicaciones sobre una plataforma administrada.

Firebase puede utilizarse como parte de una arquitectura basada en servicios cloud.

I

IaaS

Infraestructura como servicio

Utilizamos máquinas virtuales, redes y almacenamiento virtual.

Ejemplo: una máquina virtual Ubuntu en Cloud.

04

DÓNDE ESTÁN LOS RECURSOS

Computación Local vs Cloud

💻 LOCAL
  • Los recursos están en nuestro equipo.
  • Dependemos directamente del hardware.
  • Los archivos se almacenan localmente.
  • Ejemplo: un archivo HTML guardado en el computador.
☁ CLOUD
  • Los recursos son accesibles mediante Internet.
  • Los datos pueden almacenarse en servicios cloud.
  • Permite acceder desde distintos dispositivos.
  • CloudStock utiliza Firebase Firestore como base de datos cloud.

¿Qué hace CloudStock?

El sitio web está publicado mediante GitHub Pages. JavaScript se conecta directamente con Firebase Firestore para consultar los productos almacenados en la nube. Los productos pueden visualizarse desde el navegador y agregarse a un carrito.

CONCEPTOS FUNDAMENTALES

Conceptos utilizados

Hosting

Servicio que aloja y publica recursos de una aplicación o sitio web.

Firestore

Base de datos NoSQL de Firebase utilizada para almacenar los productos.

HTTPS

Protocolo utilizado para transmitir información de forma segura en la web.

GitHub

Plataforma utilizada para almacenar y publicar el código del proyecto.

Deploy

Proceso de publicar una aplicación para que pueda ser utilizada.
