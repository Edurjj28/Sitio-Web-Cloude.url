CONCEPTO PRINCIPAL

¿Qué es Cloud Computing?

Computar

Computar es procesar información mediante recursos tecnológicos. Un computador recibe datos, los procesa, puede almacenarlos y entrega un resultado.

CPU RAM Almacenamiento SO Aplicaciones Red

☁ Cloud Computing

Es el uso bajo demanda de recursos informáticos a través de una red, normalmente Internet.

Puede incluir almacenamiento, servidores, bases de datos, aplicaciones, procesamiento y redes.

Idea clave: la nube utiliza infraestructura física real. Existen servidores físicos en centros de datos, pero el usuario no necesita poseer ni administrar toda esa infraestructura.
02

MODELOS DE SERVICIO

SaaS, PaaS e IaaS

S

SaaS

Software como servicio

Usamos una aplicación lista para funcionar.

Ejemplo: Microsoft 365.

P

PaaS

Plataforma como servicio

Desplegamos aplicaciones sobre una plataforma administrada.

La plataforma administra parte de la infraestructura.

I

IaaS

Infraestructura como servicio

Utilizamos máquinas virtuales, redes y almacenamiento virtual.

Ejemplo: una máquina virtual Ubuntu contratada en Cloud.

03

DÓNDE ESTÁN LOS RECURSOS

Computación Local vs Cloud

💻 LOCAL
  • Los recursos están en nuestro equipo.
  • Dependemos directamente del hardware y su disponibilidad.
  • Para aumentar la capacidad normalmente debemos mejorar o reemplazar el equipo.
  • Ejemplo: index.html guardado en el computador.
☁ CLOUD
  • Los recursos son accesibles mediante Internet.
  • Pueden estar disponibles desde distintos dispositivos.
  • Puede facilitar escalabilidad, colaboración, respaldo y despliegue.
  • Presenta desafíos de conectividad, seguridad, costos, privacidad y dependencia del proveedor.

¿Qué ocurrió con una página HTML local?

Si la dirección comienza con file://, el archivo está almacenado en el computador. Crear una página web no significa automáticamente publicarla en la nube: para que otras personas accedan sin recibir el archivo, se necesita una infraestructura que entregue la página públicamente.

CONCEPTOS FUNDAMENTALES

Conceptos que nacen del problema

Hosting

Servicio que aloja y publica recursos de una aplicación o sitio.

HTTP / HTTPS

Protocolos utilizados para intercambiar recursos web.

IP

Identifica un dispositivo o interfaz en una red.

DNS

Relaciona nombres fáciles de recordar con direcciones utilizadas en la red.

Deploy

Proceso de publicar una versión de una aplicación para que pueda utilizarse.
