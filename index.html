TECNOLOGÍA

¿Qué es Cloud Computing?

El Cloud Computing o computación en la nube permite utilizar recursos informáticos a través de una red o Internet, sin necesidad de tener toda la infraestructura físicamente en nuestro equipo.

Estos recursos pueden incluir almacenamiento, servidores, bases de datos, aplicaciones y otros servicios.

Aunque hablamos de "la nube", los recursos realmente funcionan sobre infraestructura física ubicada en centros de datos.

SERVICIOS

Modelos de servicio Cloud

01

SaaS

Software as a Service.

El usuario utiliza directamente una aplicación proporcionada por un proveedor.

Ejemplo: Microsoft 365
02

PaaS

Platform as a Service.

Proporciona una plataforma para desarrollar y ejecutar aplicaciones sin administrar toda la infraestructura.

Ejemplo: Firebase
03

IaaS

Infrastructure as a Service.

Permite utilizar recursos de infraestructura como máquinas virtuales, almacenamiento y redes.

Ejemplo: una máquina virtual Ubuntu

COMPARACIÓN

Local vs Cloud

🖥️ Sistema local

  • Los datos se almacenan localmente.
  • Depende del equipo o servidor físico.
  • Puede ser más difícil acceder desde otros dispositivos.
  • Se debe mantener la infraestructura.

☁️ Sistema Cloud

  • Los datos se almacenan en servicios de nube.
  • Se puede acceder desde diferentes dispositivos.
  • La infraestructura es administrada por el proveedor.
  • Facilita la disponibilidad y escalabilidad.

¿Dónde está CloudStock?

CloudStock utiliza GitHub Pages para publicar la página web y Firebase Firestore para almacenar los productos en la nube.
