¿Qué es Cloud Computing?

La computación en la nube permite usar recursos informáticos a través de Internet, sin tener toda la infraestructura en tu propio equipo. Esos recursos incluyen almacenamiento, servidores, bases de datos y aplicaciones.

Aunque hablamos de "la nube", todo funciona sobre infraestructura física ubicada en centros de datos.

Modelos de servicio Cloud

SaaS

Software as a Service

El usuario utiliza directamente una aplicación entregada por un proveedor.

Ejemplo: Microsoft 365

PaaS

Platform as a Service

Entrega una plataforma para desarrollar y ejecutar aplicaciones sin administrar la infraestructura.

Ejemplo: Firebase

IaaS

Infrastructure as a Service

Permite usar máquinas virtuales, almacenamiento y redes como recursos.

Ejemplo: una máquina virtual Ubuntu

Local vs Cloud

🖥️ Sistema local

  • Los datos se guardan en el propio equipo.
  • Depende de un servidor físico.
  • Es más difícil acceder desde otros dispositivos.
  • Tú mantienes la infraestructura.

☁️ Sistema Cloud

  • Los datos viven en servicios de nube.
  • Se accede desde cualquier dispositivo.
  • El proveedor administra la infraestructura.
  • Facilita la disponibilidad y la escalabilidad.

¿Dónde está CloudStock? La página se publica en GitHub Pages, los productos se guardan en Firebase Firestore y el acceso se controla con Firebase Authentication.

¿Cómo funciona CloudStock?

  1. NavegadorEl usuario abre CloudStock.
  2. GitHub PagesPublica los archivos de la página.
  3. AuthenticationVerifica quién es el usuario y su rol.
  4. FirestoreGuarda los productos y aplica las reglas de seguridad.

Conceptos utilizados

Hosting

Servicio que almacena y publica un sitio web.

Firestore

Base de datos de Firebase donde se guardan los productos.

Authentication

Servicio que identifica a cada persona con correo y contraseña.

Reglas de seguridad

Definen en el servidor quién puede leer y quién puede modificar los datos.

HTTPS

Protocolo que cifra la comunicación con el sitio.

Deploy

Proceso de publicar una aplicación para que se pueda usar.
